# Online Store Project
Проект интернет-магазина с системами управления товарами и категориями.

## Реализованный функционал

#### **Базовый класс Product (Товар)**
- **Атрибуты:** название, описание, цена, количество
- **Приватные атрибуты:** цена (`__price`)
- **Геттеры/сеттеры:** валидация цены с подтверждением понижения
- **Класс-методы:** `new_product()` - создание товара из словаря с проверкой дубликатов
- **Магические методы:**
  - `__str__()`: `"Название, X руб. Остаток: X шт."`
  - `__add__()`: сложение стоимости товаров на складе (только одинаковые классы)
- **Строковое представление:** `"Название, X руб. Остаток: X шт."`

#### **Класс Smartphone (Смартфон) - наследник Product**
- **Дополнительные атрибуты:**
  - `efficiency` - производительность
  - `model` - модель
  - `memory` - объем встроенной памяти
  - `color` - цвет
- **Наследует** всю функциональность базового класса Product

#### **Класс LawnGrass (Трава газонная) - наследник Product**
- **Дополнительные атрибуты:**
  - `country` - страна-производитель
  - `germination_period` - срок прорастания
  - `color` - цвет
- **Наследует** всю функциональность базового класса Product

#### **Класс Category (Категория)**
- **Приватные атрибуты:** список товаров (`__products`)
- **Методы:** `add_product()` - защищенное добавление товаров (только Product и наследники)
- **Магические методы:**
  - `__str__()`: `"Название, количество продуктов: X шт."`
  - `__iter__()`: поддержка итерации по товарам
  - `__len__()`: количество товаров в категории
- **Геттеры:** 
  - `products` - строковое представление товаров
  - `products_list` - доступ к списку товаров
- **Автоматический подсчет:** количества товаров и категорий

#### **Класс CategoryIterator (Итератор категории)**
- **Назначение:** перебор товаров категории в цикле for
- **Методы:** `__iter__()`, `__next__()`
- **Использование:** `for product in category:`

### Система защиты данных

#### Защита целостности данных:
- Приватный список товаров в категориях
- Контролируемое добавление товаров через `add_product()`
- Приватная цена товара с валидацией
- Подтверждение понижения цены
- Проверка дубликатов товаров

#### Валидации:
- Цена не может быть нулевой или отрицательной
- Автоматическое объединение дубликатов товаров
- Выбор максимальной цены при конфликте

### Особенности
- Автоматический подсчет товаров и категорий
- Загрузка данных из JSON файла

### Новая функциональность

#### Строковые представления:
- **Товар:** `"iPhone 15, 100000.0 руб. Остаток: 5 шт."`
- **Категория:** `"Смартфоны, количество продуктов: 15 шт."`

#### Математические операции:
```python
product1 = Product("Товар1", "Описание", 100.0, 2)  # 200 руб
product2 = Product("Товар2", "Описание", 200.0, 3)  # 600 руб
total = product1 + product2  # 800 руб
