# Online Store Project
Проект интернет-магазина с системами управления товарами и категориями.

## Реализованный функционал

### Модели данных
- **Product** - класс товара с атрибутами: название, описание, цена, количество
- **Category** - класс категории товаров с автоматическим подсчетом количества товаров и категорий

### Особенности
- Автоматический подсчет товаров и категорий
- Загрузка данных из JSON файла

### Технологический стек
- **Python 3.14** - язык программирования
- **Poetry 1.8** - управление зависимостями
- **Pytest 8.4** - тестирование с покрытием
- **Mypy 1.18** - статическая типизация
- **Flake8 7.3** - проверка стиля кода
- **Black 25.9 & isort 7.0** - автоматическое форматирование
